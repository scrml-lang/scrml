- Work in your worktree. Commit incrementally; keep `docs/changes/<lane>/progress.md` current (crash-recovery anchor).

If the hook fails, fix the cause or report it; a hook bypass needs the OWNER's explicit authorization (never standing). Run the pre-commit hook in the FOREGROUND (Bash timeout 600000; it takes 6–16 min). If an env prefix is allowed, use `SCRML_HOOK_SHARD_MEM_MB=4608`; if refused, run without. Do not end your turn with background work running.
