## Conformance-blocking (new)
1. **`:error` declaration kind / E-ERROR-008** (FAILs error/error-008-message-pos, error-008-neg). §19.1 "Error types are enum types (§14.4)"; `:error` appears only in §14.1.2's loci list; E-ERROR-008's §34 row points at §19.2 (the `renders` clause); no normative text reserves `message`/`type`. 3 corpus uses. Rec (PERMANENT): error types are enums — strike `:error` from §14.1.2, retire E-ERROR-008, rewrite the neg case to `:enum`, retire the pos case. Capable alternative: payload fields on variants (`Failed(message: string)`); authors lose nothing.
2. **E-DG-001 on mutual server-function recursion** (FAIL reactive/dg-001-cyclic-pos, gap g-boot-dg-001-call-cycle-unruled-s478). Rec (PERMANENT, capability-keeping): recursion between server functions is NOT E-DG-001; re-scope the §34 row to the reactive-graph sense (or retire it for E-DERIVED-CIRCULAR-DEP / E-RESET-ON-CYCLE) and retire the case. Searched §31.2, §13 — no rule forbids recursion.

## §3.B items with no prior rec
3. **g-boot-schema-type-case-s478** — Rec (PERMANENT): §39.4 type names and §39.2 constraint words case-insensitive, lowercase canonical (`id: INTEGER` accepted). SQL keywords are case-insensitive; raw DDL in the same block already accepts `INTEGER`; impl#1 already lowercases.
4. **g-boot-schema-second-pk-code-s478** — Rec (PERMANENT): mint E-SCHEMA-018, Error. §39.5 "Exactly one column per table MAY be designated `primary key`." Capable alternative: table-level `PRIMARY KEY (a, b)` in raw DDL.
5. **§38.7 channel reconnect (g-boot-channel-s478 Q6)** — Rec (PERMANENT, capability gain): specify, don't drop: `reconnect=` is the initial delay, doubling with ±20% jitter to a 30 s cap; reset on open; `0` disables. A fixed delay reconnects every client in lockstep after a server restart.
6. **X-Forwarded-* trust (g-boot-channel-xfwd-first-entry-s478)** — Rec (PERMANENT): `<program trusted-proxies=N>` (N = the number of proxies in front of the server; the client IP is the Nth-from-last X-Forwarded-For entry; 0 ignores the headers). **PA amendment to the triage rec: default 0, not 1** — with no proxy deployed, "trust the last entry" trusts a header the client wrote, so a default of 1 fails open; 0 fails closed and a proxied deploy states its count (the `scrml build --target fly|railway|render` targets can set it). Same rule for `ratelimit=`, whose §40.2.4 "first value" reading lets any client spoof its IP.
7. **g-boot-engine-self-write-outside-lint-s478** — Rec (PERMANENT): drop the conservative firing outside a state-child (§51.0.F.1); keep the strict inside-state-child half. Under §66 a function-body engine write is the canonical idiom.
8. **g-boot-timing-compositions-s478** — Rec (PERMANENT): a `debounced=`/`throttled=` engine cell transitions at commit — `rule=` judged and `<onTransition>` run at commit; violation = runtime E-ENGINE-INVALID-TRANSITION. Mitigate with a static check of literal held writes. Searched §6.13.5, §51.0 — none.
9. **GET `<endpoint>` input (g-boot-endpoint-residue-s478 item 2)** — Rec (PERMANENT): GET/DELETE read §41.13 input from the query string (strict keys, primitive payload fields only; non-primitive = compile error); POST/PUT/PATCH keep the JSON body; add "GET arms SHOULD be safe" to §61.7 (415 does not protect GET).
10. **`log()` build mode (g-boot-s20-builtins-unbuilt-s473)** — Rec (PERMANENT): `scrml-boot dev` builds development, `scrml-boot compile` builds production (`--dev` opts in); the deployed artifact fails safe (§20.6.8 `log()` emits zero bytes). impl#1 is the reverse — recorded divergence.
11. **#1917 loop narrowing** — Rec: PERMANENT — write the shipped reading into §42.3.5 (a write to the narrowed place anywhere in a loop's head or body ends the narrowing for the whole loop and after it — back-edge); INTERIM — the extra drop on nested-function calls lifts once nested write sets are computed; a presence-test `for` head narrows its body (§42.4 statement 2 addition).
12. **S477 carried: #1793 readings** — (i) stale (ruled S478); (ii) CONFIRM INTERIM (capable form S4's handled waiting write); (iii) CONFIRM PERMANENT: one E-VALUE-SERVER-CALL report per declaration; file a gap for the unnamed derived-with-lifecycle refusal.
13. **`.join` on `int[]`** — Rec (PERMANENT): admit `.join(sep)` on primitive and unit-enum elements via the §20.7.2 template text; refuse struct/tape/payload-enum elements (alternative `xs.map(fmt).join(sep)`).
14. **O9 slot spelling (§66.15.2)** — Rec: refusal INTERIM until built; spelling PERMANENT: named `<slot name="header"/>` filled by `slot="header"` (the legacy §16 surface, mechanical codemod); per-row `<slot name="row" of=it/>` bound by `as=r` at the filler.
